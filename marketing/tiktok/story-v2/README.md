# «Три двери»: длинная версия с новой озвучкой

[Скачать MP4](tarot-story-v2.mp4). Вертикальный ролик около 83 секунд, 720×1280, с русским голосом и субтитрами. Призыв в конце ведёт в @tarott_online_bot.

Сюжет: предупреждение → три двери и гаснущий фонарь → ложные обещания → проверка светом → выход к рассвету → вопрос зрителю → настоящее приложение бота.

Озвучка заново синтезирована Silero CIS `v5_cis_base`, голос `ru_dmitriy`. Модель опубликована под MIT; лицензия сохранена рядом. Голос из присланного TikTok не клонировался, точное сходство с ним не подтверждено. Референс владельца: https://vm.tiktok.com/ZN8y5PpKN/ — «Глобальный блэкаут на 32 этаже — часть 3», длительность по метаданным 92 секунды. Копия референса в репозиторий не включена.

В ролике анимированы два сгенерированных изображения и использована запись настоящего интерфейса приложения. Это монтаж с движением камеры и переходами, без внешней платной image-to-video генерации. Музыкальная подложка не заимствована: фон синтезирован при монтаже.

`script.json` содержит текст, `timing.json` — хронометраж, `voice-*.wav` — отдельные реплики. `synthesize.py` требует PyTorch CPU, NumPy и локальную модель `/workspace/.local/voices/v5_cis_base.pt`. `render.py` использует ffmpeg и Noto Sans, а также исходную запись из `../real-app-source/` и ключевой кадр из `../survival/`. Промежуточные клипы создаются в игнорируемой папке `work/`.
