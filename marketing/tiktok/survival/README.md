## Что сделано

Сгенерировано изображение фантазийной локации с тремя дверями: Солнце, Луна и Звезда. В пробном ролике используется плавное приближение к этому кадру, затем настоящая запись приложения из `../real-app-source/app-real.webm`. Добавлены русская нейросетевая озвучка Piper, титры, синтезированный атмосферный звук и переход к Telegram-боту. Новые сцены с полноценным нейросетевым движением в этом сеансе не генерировались: текущая версия — анимированный ключевой кадр + настоящая запись экрана.

Это тест формата, не подтверждение его вирусности. История про двери — вымышленная игровая сцена, а не обещание предсказания или способ выживания в реальной ситуации.

## Сценарий озвучки

«Ты проснулся в мире Таро. Перед тобой три двери. До рассвета откроется только одна. Солнце, Луна или Звезда? Какую выберешь? А свой расклад открой в Телеграм. Тарот онлайн бот».

Подпись для публикации:

> Солнце, Луна или Звезда — какую дверь выберешь? Это наша фантазийная история в мире Таро. А свой расклад можно открыть в Telegram: @tarott_online_bot. #таро #таробот #pov

Для AI-сцен и синтетического голоса использовать актуальную маркировку AI-контента, доступную при публикации в TikTok. Условия и интерфейс маркировки проверить в самом аккаунте: полный текст официальной справки в этом сеансе не загрузился.

## Модули и повторение

В этой рабочей среде установлены Piper TTS и официальный Runway SDK в изолированном `/workspace/scratch/video-tools-venv`. Настройки опубликованной облачной среды не изменялись, платные подписки не оформлялись. Публикация этих файлов в GitHub не публикует ролики в соцсетях.

Для новой машины: Python 3.12, ffmpeg, Noto Sans, отдельный venv и `pip install -r marketing/tiktok/survival/requirements-video.txt`. Пример:

```bash
python -m venv /workspace/scratch/video-tools-venv
/workspace/scratch/video-tools-venv/bin/pip install -r marketing/tiktok/survival/requirements-video.txt
```

`render.py` использует сохранённые WAV-сегменты. Запуск из корня репозитория: `python marketing/tiktok/survival/render.py`. На другой платформе исправить пути к шрифтам. Промежуточные `part-*.wav`, `filter.txt` и `caption-*.txt` можно пересоздать этим скриптом.

### Полноценная генерация движения

Подготовлен `generate_motion.py` по официальной документации Runway. Локальная проверка выполнена:

```bash
/workspace/scratch/video-tools-venv/bin/python marketing/tiktok/survival/generate_motion.py --dry-run
```

Для внешнего вызова нужен аккаунт Runway Dev с балансом и переменная `RUNWAYML_API_SECRET`, которой в проверенной среде нет. Значение хранить в защищённых настройках, не в репозитории и не в сообщениях. Хост API: `api.dev.runwayml.com`. Авторизация и генерация на сервере не проверены. Текущую цену пятисекундной генерации необходимо проверить в аккаунте до расходования бюджета $20; этот документ не гарантирует стоимость и не резервирует кредиты.

После настройки доступа `--submit` отправляет ровно один пятисекундный запрос `gen4.5`, сохраняет ID задачи и ждёт результат. Повторный запуск существующей задачи — через `--task-id`, без повторной генерации. Автоматические повторы создания задачи отключены. Не пересоздавать задачу при таймауте ожидания. В текущем ролике `doors-motion.mp4` автоматически не подменяется: после получения видео нужно проверить его и заменить первый план монтажа отдельно.
